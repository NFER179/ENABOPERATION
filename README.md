# ENABOPERATION

Aplicación web desarrollada como proyecto académico, orientada a la gestión de operaciones mediante una arquitectura basada en Java/JSP.

## Descripción

El repositorio contiene una aplicación web estructurada en componentes de presentación, modelo, utilidades y acceso a datos. La estructura incluye módulos para `WebContent`, `model`, `helper` y `database`, además de los recursos necesarios para compilar y ejecutar el proyecto.

## Tecnologías

- Java
- JSP (JavaServer Pages)
- Aplicación web
- Persistencia de datos

## Estructura

- `JSP/`: implementación principal de la aplicación web.
- `JSP/WebContent/`: recursos de la interfaz web.
- `JSP/model/`: componentes asociados al modelo de la aplicación.
- `JSP/helper/`: clases auxiliares y utilidades.
- `JSP/database/`: componentes relacionados con la base de datos.
